# 제목 없는 RPG 게임 무기 데미지 계산기

로블록스 **제목 없는 RPG 게임**의 **고낙·심파·심빛·심끝·망집** 강화·품질별 데미지를 계산하는 정적 웹 페이지입니다.

## 바로 사용하기

**[무기 데미지 계산기 열기](https://dubble95.github.io/untitled-rpg-damage-calculator/)**

설치나 회원가입 없이 브라우저에서 바로 사용할 수 있습니다.

## 지원 무기

| 줄임말 | 무기 | 0강 100품 공격력 |
|---|---|---:|
| 고낙 | 고대 낚싯대 | 315 ~ 630 |
| 심파 | 심연의 파동 | 345 ~ 690 |
| 심빛 | 심연 속의 빛 | 380 ~ 760 |
| 심끝 | 심연의 끝 | 440 ~ 880 |
| 망집 | 망각의 집행자 | 550 ~ 1,100 |

## 기능

- 강화 **0~70강**, 품질 **1~100품** 입력
- 최소~최대 데미지 실시간 계산 및 `10.55k` 형식의 간략한 수치 표시
- 같은 강화·품질 조건에서 다섯 무기 비교
- 결과 클립보드 복사
- 현재 무기·강화·품질 조건을 URL에 저장하고 공유
- 모바일·데스크톱 반응형 화면
- 외부 라이브러리·서버·빌드 과정 없이 HTML 한 파일로 동작

## 계산식

2026년 10월 23일 업데이트로 낮은 품질의 데미지가 상향된 이후 공식을 사용합니다. 품질 100%의 데미지는 기존과 같고, 품질 1%의 데미지 계수는 기존 50.5%에서 67%로 상승했습니다.

```text
변경 전: 최종 데미지 = 0강 100품 공격력 × (100 + 품질) ÷ 200 × 1.07^강화
변경 후: 최종 데미지 = 0강 100품 공격력 × (200 + 품질) ÷ 300 × 1.07^강화
```

최소 데미지에는 무기별 최소 기본 공격력을, 최대 데미지에는 최대 기본 공격력을 적용합니다. 스킬·유물 등의 외부 보정은 포함하지 않습니다.

예를 들어 심연의 끝 45강 93품의 최대 데미지는 `880 × (200 + 93) ÷ 300 × 1.07^45 = 18,050.91`이며, 게임 툴팁에는 `18.05K`로 표시됩니다.

무기 기본 공격력과 계산식은 [나무위키 「제목 없는 RPG 게임/무기」](https://namu.wiki/w/%EC%A0%9C%EB%AA%A9%20%EC%97%86%EB%8A%94%20RPG%20%EA%B2%8C%EC%9E%84/%EB%AC%B4%EA%B8%B0)와 [r48 → r49 공식 변경 기록](https://namu.wiki/diff/%EC%A0%9C%EB%AA%A9%20%EC%97%86%EB%8A%94%20RPG%20%EA%B2%8C%EC%9E%84/%EB%AC%B4%EA%B8%B0?uuid=70c0abf4-2ec0-477b-9063-ef0ebc45469d)을 기준으로 합니다. 품질 상향은 [공식 디스코드](https://discord.gg/syJnnQky4W)의 2026년 10월 23일 업데이트 공지에서 확인했습니다. 실제 게임과 차이가 있을 수 있으므로 최종 수치는 게임 내 툴팁으로 확인해야 합니다.

## 로컬에서 열기

```bash
git clone git@github.com:dubble95/untitled-rpg-damage-calculator.git
cd untitled-rpg-damage-calculator
open index.html  # macOS
```

Windows에서는 `index.html`을 브라우저로 열면 됩니다.

## URL로 조건 공유

현재 조건은 주소의 `weapon`, `r`, `q` 값에 저장됩니다.

```text
https://dubble95.github.io/untitled-rpg-damage-calculator/?weapon=망집&r=12&q=95
```

위 예시는 망각의 집행자 12강 95품입니다.
