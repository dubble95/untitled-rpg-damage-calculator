# 제목 없는 RPG 게임 무기 데미지 계산기

로블록스 **제목 없는 RPG 게임**의 **고낚·심파·심빛·심끝·망집** 강화·품질별 데미지를 계산하는 정적 웹 페이지입니다.

## 바로 사용하기

**[무기 데미지 계산기 열기](https://dubble95.github.io/untitled-rpg-damage-calculator/)**

설치나 회원가입 없이 브라우저에서 바로 사용할 수 있습니다.

| 줄임말 | 무기 | 0강 100품 공격력 |
|---|---|---:|
| 고낚 | 고대 낚싯대 | 315 ~ 630 |

## 기능

- 강화 **0~70강**, 품질 **1~100품** 입력
- 최소~최대 데미지 실시간 계산 및 `10.55k` 형식의 간략한 수치 표시
- 결과 범위에 무기별 고정값인 0강 1품 최소~100품 최대 데미지 표시
- 무기별 기본 비용과 강화 단계별 비용 증가를 반영한 예상 강화 비용 계산기
- 같은 강화·품질 조건에서 다섯 무기 비교
- 결과 클립보드 복사
- 현재 무기·강화·품질 조건을 URL에 저장하고 공유
- 모바일·데스크톱 반응형 화면
- 외부 라이브러리·서버·빌드 과정 없이 HTML 한 파일로 동작

### 예상 강화 비용 계산 (게임 화면 캡처 기반 추정)

게임 화면의 강화 비용·성공 확률·천장 캡처를 바탕으로 강화 비용과 확률을 추정합니다. 1회 비용은 **무기별 0강 기본 비용 × 1.1^현재 강화 단계**, 성공 확률은 **100% × 0.86^현재 강화 단계**, 천장 횟수는 **round(250 ÷ 성공 확률[%])**로 계산합니다. 화면에는 0강 기본 비용이 아니라 선택한 무기와 현재 강화에 따른 1회 비용을 표시합니다.

캡처와의 비교: 오빌리언 리프트 I +5강은 24.15K·성공률 47.04%·천장 5회, 고대 낚싯대 +25강은 151.63K·2.3%·109회, 오빌리언 리프트 III +34강은 363.21K·0.592%·422회, 심연의 끝 +45강은 1.31M·0.112%·2,216회입니다. 리프트 I·III의 기본 비용은 각각 14.995K, 14.217K로 단계별 비용 캡처에서 역산했습니다. 표시 자릿수와 캡처 표본이 제한되어 있으므로 공식 수치가 아닌 근사치로 봐야 합니다.

계산 가정:
- 강화 1회 비용은 단계가 오를 때마다 10% 복리로 증가
- 강화 성공 확률과 천장은 현재 강화 단계에 따라 자동 계산
- 실패 시 강화 수치는 유지된다고 가정
- 천장은 추정 성공 확률의 약 2.5배 역수로 설정
- 예상 비용은 각 강화 단계의 1회 비용에 해당 단계의 예상 시도 횟수를 곱해 합산

입력 항목:
- **강화**: 위쪽 데미지 계산의 현재 강화 단계가 비용 계산 시작 단계로 자동 반영
- **추가 강화**: 현재 강화에서 더 올릴 단계 수. 기본값은 `+1`이며 목표는 현재 강화 + 입력값 (최대 70강)
- **현재 강화 비용**: 선택한 무기의 현재 강화 단계에서 1회 강화에 드는 추정 비용을 표시
- **현재 성공 확률 / 천장**: 현재 강화 단계로부터 추정해 표시하며, 여러 단계를 계산할 때는 각 단계별 값이 적용


## 계산식

2026년 10월 23일 업데이트로 낮은 품질의 데미지가 상향된 이후 공식을 사용합니다. 품질 100%의 데미지는 기존과 같고, 품질 1%의 데미지 계수는 기존 50.5%에서 67%로 상승했습니다.

```text
변경 전: 최종 데미지 = 0강 100품 공격력 × (100 + 품질) ÷ 200 × 1.07^강화
변경 후: 최종 데미지 = 0강 100품 공격력 × (200 + 품질) ÷ 300 × 1.07^강화
```

최소 데미지에는 무기별 최소 기본 공격력을, 최대 데미지에는 최대 기본 공격력을 적용합니다. 스킬·유물 등의 외부 보정은 포함하지 않습니다.

예를 들어 심연의 끝 45강 93품의 최대 데미지는 `880 × (200 + 93) ÷ 300 × 1.07^45 = 18,050.91`이며, 게임 툴팁에는 `18.05K`로 표시됩니다.

무기 기본 공격력과 계산식은 [나무위키 「제목 없는 RPG 게임/무기」](https://namu.wiki/w/%EC%A0%9C%EB%AA%A9%20%EC%97%86%EB%8A%94%20RPG%20%EA%B2%8C%EC%9E%84/%EB%AC%B4%EA%B8%B0)와 [r48 → r49 공식 변경 기록](https://namu.wiki/diff/%EC%A0%9C%EB%AA%A9%20%EC%97%86%EB%8A%94%20RPG%20%EA%B2%8C%EC%9E%84/%EB%AC%B4%EA%B8%B0?uuid=70c0abf4-2ec0-477b-9063-ef0ebc45469d)을 기준으로 합니다. 품질 상향은 [공식 디스코드](https://discord.gg/syJnnQky4W)의 2026년 10월 23일 업데이트 공지에서 확인했습니다.

### 오차 추정 및 기본 공격력 수정

게임 스크린샷과 계산 결과를 비교한 결과입니다.

| 조건 | 계산값 | 게임 툴팁 | 오차 |
|------|--------|-----------|------|
| 망각의 집행자 +57, 99품 최대 | 52,330 (52.33k) | 52.32k | 0.02% |
| 망각의 집행자 +0, 4품 최대 | 754.8 | 754.8 | 0% |

공식 <i>P × (200 + Q) ÷ 300 × 1.07<sup>R</sup></i>은 고강화·고품질 구간에서 게임 툴팁과 거의 정확히 일치합니다.

**기본 공격력 수정:** 망각의 집행자의 기본 공격력이 게임 업데이트로 변경되어 계산기의 기본값을 550~1,100에서 **555~1,110**로 수정했습니다. (기존 1,100 → 실제 1,110)

품질이 낮을 때 게임 UI의 품질 표시가 정수로 반올림되어 최대 ~1% 내외 오차가 발생할 수 있습니다. 계산기 품질 입력란에 소수점(예: 5.85)을 직접 입력하면 더 정확하게 맞출 수 있습니다.

실제 게임과 차이가 있을 수 있으므로 최종 수치는 게임 내 툴팁으로 확인해야 합니다.

## 로컬에서 열기

```bash
git clone git@github.com:dubble95/untitled-rpg-damage-calculator.git
cd untitled-rpg-damage-calculator
open index.html  # macOS
```

Windows에서는 `index.html`을 브라우저로 열면 됩니다.

## URL로 조건 공유

현재 조건은 주소의 `weapon`, `r`, `q` 값에 저장됩니다.

```text
https://dubble95.github.io/untitled-rpg-damage-calculator/?weapon=망집&r=12&q=95
```

위 예시는 망각의 집행자 12강 95품입니다.

## 테스트

Node.js 18 이상에서 별도 패키지 설치 없이 실행할 수 있습니다.

```bash
npm test
```

`index.html`의 실제 계산·표시 함수를 읽어 검증하며, 기본 공격력, 무기별 고정 품질 범위, 게임 화면 검증 사례, `k` 단위 경계, 100품 70강 망집의 `126.53k` 회귀 사례, `m·b·t` 단위를 검사합니다.
